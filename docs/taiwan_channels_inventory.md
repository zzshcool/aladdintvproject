## 三、ofiii 三立新聞台 (setnews) APK 實機可行性驗證報告

### 1. 播放器架構與 DOM 定位
- **網址結構**：`https://www.ofiii.com/channel/watch/setnews`
- **架構特徵**：ofiii 為 Next.js / React 構建之 SPA 單頁式 Web 應用程式。
- **DOM 定位**：播放核心位於網頁主體頂層容器中，渲染為標準 HTML5 `<video>` 標籤，**非** 跨域 `<iframe>` 嵌入。
- **WebView 整合要求**：
  - 必須啟用 `JavaScriptEnabled = true`、`domStorageEnabled = true` 及 `databaseEnabled = true`。
  - 必須設定合規 User-Agent，並將 `ofiii.com` 列入導航白名單，避免非預期外跳。

### 2. 前貼片廣告與 Video 元素替換行為
- **廣告機制**：起播時會載入 Google IMA / VAST 前貼片視訊廣告（約 15 至 30 秒）。
- **DOM 節點置換**：
  - 廣告播放期間，DOM 樹中存在廣告專用 `<video>` 節點。
  - 廣告結束切入正片直播時，React 會**銷毀並移除**廣告 video 節點，並重新插入正片直播 `<video>` 節點。
  - **限制與修正**：傳統在 `onPageFinished` 一次性綁定 `document.querySelector('video')` 會在廣告結束後失效失聯。本專案已在 `YouTubeIframePlayerView` 中導入 `MutationObserver` 動態監聽 DOM 樹變更，自動對新創建的 video 節點重新綁定播放進度監控，並徹底清理舊計時器。

### 3. 全螢幕、遙控器與返回鍵行為
- **全螢幕機制**：ofiii 播放器依賴 CSS 全螢幕樣式與 HTML5 Fullscreen API。WebView 需由 `WebChromeClient.onShowCustomView` 與 `onHideCustomView` 接管全螢幕視圖。
- **遙控器焦點**：電視盒遙控器操作下，網頁中的暫停按鈕、選集列表容易意外搶奪焦點。主 App 需將遙控器方向鍵劫持於原生層，避免網頁焦點錯亂。
- **返回鍵退出**：返回鍵透過 `handleBackPress()` 優先處理全螢幕退出及 `webView.canGoBack()`，避免單擊返回直接退出應用程式。

### 4. 網路重連與合法接入限制明示
- **防盜鏈與 Token 機制**：ofiii 之後端 HLS 串流採用動態簽章與短效 Session Token 鑑權，不提供對外公開的永久性 m3u8 網址。
- **合法合規接入原則**：
  - 本專案**嚴格禁止**破解 DRM、擷取短效 Token、繞過廣告或反向代理串流。
  - 合法正式方案一律以 APK 內 WebView 載入官方觀看頁為主。
- **網路重連與中斷限制**：若網路斷線，ofiii 網頁會彈出「連線逾時，請重新載入」之覆蓋層，且無法自動恢復正片播放。此時必須由主調度器的緩衝看門狗超時後自動重載或切換備援。
